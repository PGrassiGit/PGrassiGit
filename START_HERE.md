## 🚀 Quick Start (3 Steps)

### Step 1: Configure Your Site
Edit `_config.yml` and update:
- Your name and email
- Site title and description
- Your GitHub Pages URL

### Step 2: Fill In Your Content Pages
- Update `about.md` with your bio
- Update `cv.md` with your resume
- Add your contact info to `contact.md`

### Step 3: Push to GitHub
```bash
git add .
git commit -m "Portfolio setup complete"
git push origin main
```

Your site will be live in 2-5 minutes at `https://yourusername.github.io`
